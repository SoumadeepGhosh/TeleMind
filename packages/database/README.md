# @telemind/database

Database layer for TeleMind powered by Prisma ORM and PostgreSQL with `pgvector`.

## Features
- Schema definition with PostgreSQL extensions (`pgvector`, `uuid-ossp`, `pg_trgm`).
- Vector embeddings support (`vector(768)`) for Google Gemini AI embeddings.
- Full type-safety generated by Prisma Client.
- Migration and seeding scripts.

## Usage
```bash
# Generate Prisma Client
pnpm run db:generate

# Apply local migrations in dev
pnpm run db:migrate:dev

# Open Prisma Studio GUI
pnpm run db:studio
```
